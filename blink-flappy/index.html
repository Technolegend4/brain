眨眼小鸟 Blink Bird

前额脑电中的眨眼伪迹 → 实时检测 → 小鸟振翅。全部算法在浏览器本地运行，数据不上传。

零依赖 · 纯前端 因果滤波 0.5–8 Hz 延迟补偿 ≤ 450 ms

信号源

合成

合成信号包含 1/f 背景、基线漂移、50 Hz 工频、随机肌电突发和双指数眨眼模板，用来验证检测链路。

回放 0.0 / 0.0 s 检出眨眼 0 次

支持 EEG-EyeBlinks 的两种格式：分号表头（EEG-IO）与 OpenBCI 原始（EEG-VR/VV），也可直接拖到页面上。载入后会自动开始回放。

Chrome / Edge 下可用。支持 OpenBCI Cyton 二进制包（33 字节，0xA0…0xC0）。连接后在串口对话框中选中设备。

配合 python tools/bridge.py 使用：先在服务端做离线检测，再把事件按时间轴推过来。

映射与检测

就绪

基础节拍保证可玩性，眨眼会额外振翅并短暂加快节拍。

调高 → 更少误跳、更多漏跳；调低 → 更灵敏、更容易乱跳

根据最近 30 秒的实测眨眼率调整管道间隙与速度，让不同眨眼频率的人都能进入心流。
